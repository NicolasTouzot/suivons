# 0001 — Consigner les décisions en ADR

- Statut : Accepté
- Date : 2026-09-26

## Contexte

Le projet est développé par lots, en partie avec un assistant de code. Les choix structurants (stack, découpage, règles de calcul) doivent rester traçables et justifiés, au même titre que les montants affichés.

## Décision

Toute décision structurante est consignée dans `docs/adr/` au format court (contexte, décision, conséquences). Un ADR accepté n'est plus modifié ; il est remplacé par un nouvel ADR.

## Conséquences

- Une revue de code peut exiger un ADR avant fusion.
- `SPEC.md` reste la source de vérité fonctionnelle ; les ADR expliquent le « pourquoi ».
